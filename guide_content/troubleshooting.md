# Troubleshooting

## File Upload Problems

The file does not upload, or an error appears.

- Use CSV or Excel files only.
- Keep the file under 30 MB: drop columns you do not need for sampling, or save it as CSV.
- Check that the file opens normally in Excel.
- Avoid special characters in column names.

## Unrealistic Sample Sizes

- Check the population size.
- A very small margin of error makes the sample very large; 5% is common for proportions.
- With "Each stratum" as the precision target, every stratum gets a full sample. Use "Whole population only" if you only need the overall estimate.
- Check the confidence level.

## Cluster Sampling Problems

- Make sure the cluster variable is selected and has many distinct values.
- Interviews per cluster (m) must be smaller than most clusters; the frame check lists clusters that are too small.
- For the cluster-list method, the population variable must be numeric.

## Getting Help

If your problem is not covered here, contact the ATR Data Management team, or see the Sampling Guideline for methodology.
